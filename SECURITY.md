# Security Policy

## Supported versions

This project is pre-release (`0.x`). Security fixes are applied on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via GitHub Security Advisories on
[nimausername/nk-ui](https://github.com/nimausername/nk-ui/security/advisories/new)
when available, or contact the maintainer listed in `LICENSE`.

Include:

- Impact and affected paths
- Steps to reproduce
- Suggested fix if you have one

We aim to acknowledge reports within a reasonable time and coordinate a fix
before any public disclosure.
